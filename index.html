Lab Guide

Explore data mining and AI concepts with this interactive simulator.

1. Data Cleaning

  • Load "Messy Exam Marks" dataset.
  • Notice missing values, duplicates, and outliers.
  • Toggle cleaning options and see data transform.

2. Trend & Prediction

  • Load "Study Hours vs Marks" dataset.
  • Select "Trend & Prediction" method and train.
  • Drag the slider to see predicted marks.

3. Classification

  • Load "Fruit Classifier" dataset.
  • Select "Classification" and train.
  • Adjust weight and sweetness sliders to classify fruits.

4. Clustering

  • Load "Shop Customers" dataset.
  • Select "Clustering" and choose K value.
  • Train to see customer groups.

5. Group & Summarize

  • Load "Canteen Sales" dataset.
  • Select "Group & Summarize" and train.
  • See aggregated sales by item.

6. Data Bias Experiment

  • Load any dataset and delete rows of one class.
  • Train again and observe how predictions change.

7. Association Rules (Market Basket)

  • Load "Market Basket" dataset.
  • Select "Association Rules" method and train.
  • See which items are frequently bought together.

8. Decision Tree

  • Load "Weather" dataset.
  • Select "Decision Tree" method and train.
  • See how the tree splits data to predict "Play".

9. Naive Bayes

  • Load "Email Spam" dataset.
  • Select "Naive Bayes" method and train.
  • Use the classify button with word features (0 or 1).

10. Missing Value Imputation

  • Load "Missing Values Demo" dataset.
  • Select "Missing Value Imputation" method and train.
  • See mean and median for each column with missing counts.

11. Normalization

  • Load "Normalization Demo" dataset.
  • Select "Normalization" method and train.
  • Compare original vs normalized data points.

12. Outlier & Mean vs Median Demo

  • Load any numeric dataset (e.g., "Messy Exam Marks").
  • Select "Outlier & Mean vs Median Demo" and train.
  • Observe how mean is affected by outliers while median stays stable.
